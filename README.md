## 🌈 Giới Thiệu

🔥 Đây là một **website bán hàng chuyên nghiệp**, hiện đại, giao diện bắt mắt và dễ sử dụng.  
💼 Phù hợp với mọi loại hình kinh doanh online: quần áo, phụ kiện, đồ điện tử,...

> 👉 Được phát triển bằng **MERN Stack (MongoDB - Express - React - Node.js)**.  
> ⚡ Tích hợp các hiệu ứng động, thông báo realtime, và responsive full thiết bị.

---

## ✨ Tính Năng Nổi Bật

- 🎨 **Giao diện hiện đại, đẹp mắt**
- 🛒 **Giỏ hàng thông minh** – cập nhật realtime
- 🔐 **Xác thực người dùng (JWT)**
- 📦 **Quản lý đơn hàng & kho hàng**
- 📊 **Trang admin riêng biệt** với biểu đồ thống kê
- 💬 **Live Chat với khách hàng**
- 🌐 **Đa ngôn ngữ & chuẩn SEO**
